# Sanitized example output

These four records demonstrate LeadFlow's public output schema using short excerpts from public company websites. They are curated examples, not a complete discovery run or a ranked prospect list.

Contact details, account IDs, raw API payloads, model probabilities, and local database state are intentionally omitted. Every record remains `REVIEW` because public product and company-role evidence does not prove purchasing intent, import capability, or willingness to engage a new supplier.

Sources were observed on 2026-09-21 and may change. Re-check the linked official pages before relying on any claim.
